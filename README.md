# AluCar

Site de aluguel de carros com apresentação da empresa, frota e contato.

**Demo:** https://rogerrochago02.github.io/alucar/

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — estrutura, apresentação e contato
- `style.css` — estilos e layout

## Como executar

```bash
git clone https://github.com/rogerrochago02/alucar.git
```

Depois, abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
